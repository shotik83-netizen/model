# Карта источников и расчётов финансово-экономической модели

Дата актуализации: 2026-09-22  
Связанные задачи: FM-2026-007, FM-2026-008, FM-2026-010

## Проверенные источники Excel

| Источник | Назначение в приложении | Ключевые поля | Статус интеграции |
|---|---|---|---|
| `BOQ` | Контрактные объёмы, расценки СМР и МТР, трудозатраты, связь с KQ | Код и название позиции, единица, количество, ставки, KQ | Сопоставление полей есть; расчёт выполнения через BOQ требует завершения |
| `KQ` | Нормализация BOQ до аналитических групп KQ-1/KQ-2 | Код KQ, название, иерархия | Требуется явная таблица соответствия BOQ → KQ-2 |
| `КСГ` | Помесячные физические объёмы и график производства | KQ, работа, план/факт, даты, месячные колонки | Чтение источника есть; расчёт денежных объёмов требует связи с BOQ |
| `Персонал ` | Основной и косвенный персонал | Подрядчик, категория, работа, вид персонала, календарные значения | Чтение и настройка колонок есть; нужна классификация основной/косвенный |
| `Техника` | Количество и загрузка техники | Подрядчик, тип, наименование, работа, календарные значения | Чтение и настройка колонок есть; нужна агрегация в машино-часы/месяц |
| `Первичка в вал.контракта` | Фактическое выполнение, расходы, зачёт аванса, план и факт оплаты | Подрядчик, договор, вид расхода, документ, дата, суммы без/с НДС | Поля настроены; требуется приоритет факта над расчётным прогнозом |
| `Платежи` | Фактические денежные выплаты | Дата, подрядчик, договор, сумма, вид оплаты и расхода | Поля настроены; требуется распределение по статьям расходов |
| `Факторинг` | Фактическое и плановое финансирование | Договор, документ, банк, период, сумма | Поля настроены; включение в денежный поток есть |

## Расчётные зависимости

| Результат | Источник / параметр | Расчёт | Состояние |
|---|---|---|---|
| Физическое выполнение | КСГ | Сумма плановых или фактических объёмов по KQ и месяцу | Требует завершения импорта |
| Доход от работ | КСГ + BOQ + KQ-2 | Физический объём × соответствующая расценка BOQ с агрегацией до KQ-2 | Не заменять ручным процентом |
| Прямой ФОТ | Основной персонал | Численность × ставка оплаты за месяц | Реализован расчётный режим |
| НДФЛ | Прямой/косвенный ФОТ | ФОТ / (1 − ставка) × ставка | Реализовано |
| Страховые взносы | ФОТ + НДФЛ | Начисленный ФОТ × ставка категории | Реализовано укрупнённо; сверить категории Excel |
| Резерв отпусков | Годовой ФОТ | Годовой ФОТ × 8% каждый месяц | Реализовано; требуется контрольное сравнение с Excel |
| Техника | График техники | Машино-часы × ставка часа | Реализован расчётный режим |
| Материалы | BOQ/первичка | Стоимость МТР без НДС либо физический объём × ставка МТР | Частично реализовано |
| Прямые и косвенные расходы | Параметры + первичка | Расчётные статьи заменяются фактом по доступным закрытым периодам | Требуется реализовать приоритет факта |
| Финансовый результат | Доходы и расходы | Доходы без НДС − прямые расходы − косвенные расходы | Реализовано |
| Выплаты по расходам | Расходы + срок оплаты | Начисление с применимым НДС, сдвинутое на установленный срок оплаты | Реализовано |
| НДС к выплате | Поступления, авансы, зачёты, входящий НДС | Исходящий НДС + НДС с авансов − НДС с зачёта − входящий НДС, не ниже нуля | Реализован упрощённый алгоритм; показывать только в составе потока |
| Чистый денежный поток | Поступления и выплаты | Поступления − выплаты по расходам − налоговые выплаты | Реализовано |

## Правила факта и прогноза

1. В закрытых периодах использовать фактические данные первички и платежей.
2. В открытых периодах использовать расчёт по КСГ, BOQ, персоналу, технике и параметрам подрядчика.
3. Факт не должен незаметно заменяться демонстрационными значениями.
4. При отсутствии обязательного источника приложение показывает ошибку или неполноту данных, а не готовый расчёт.
5. Каждая итоговая строка должна раскрываться до источника, статьи и формулы.

## Выявленные ограничения исходной книги

- В книге 15 листов и более 60 тысяч формул.
- В XML книги присутствуют повреждённые именованные диапазоны (`#N/A`, `#REF!`), поэтому стандартное чтение книги некоторыми библиотеками завершается ошибкой.
- Для пилота формулы необходимо читать непосредственно из листов, не полагаясь на повреждённые имена.
- Сопоставление BOQ → KQ-2 и классификация персонала требуют отдельной проверки на реальных строках.
