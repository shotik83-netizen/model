# Документы c2

Папка содержит исходные документы только этого подрядчика.

Ожидаемые имена файлов:

- `boq.xlsx`
- `volume-schedule.xlsx`
- `personnel.xlsx`
- `equipment.xlsx`
- `parameters.xlsx`
- `payments.xlsx`
- `factoring.xlsx`

Файлы размещаются пользователем после выгрузки или публикации в SharePoint. Приложение не хранит рабочие данные в памяти браузера.
