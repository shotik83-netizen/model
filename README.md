# Финансово-экономическая модель

## Структура документов

- `config/config.json` — общая конфигурация приложения и ссылки на актуальные модели подрядчиков.
- `config/source-mapping.json` — шаблон карты источников для новых подрядчиков.
- `data/contractors/<contractor-id>/models/` — датированные версии модели подрядчика.
- `data/contractors/<contractor-id>/sources/` — исходные документы только этого подрядчика.

Актуальная версия модели указывается в `config/config.json`. История версий сохраняется в папке `models` и не перезаписывается. Файлы BOQ, графика объёмов, персонала, техники, параметров, платежей и факторинга не смешиваются между подрядчиками.

Приложение не использует постоянное хранилище браузера. Рабочие данные загружаются из файлов по ссылкам.

## Разработка и автономная сборка

Исходники приложения находятся в `src/`: HTML-шаблон, CSS и JavaScript разделены для безопасной разработки. Публикуемый `index.html` всегда формируется одной командой:

- `data-adapter.js` — нормализация входных данных;
- `calculation-core.js` — независимые расчётные функции;
- `app.js` — интерфейс и прикладная логика;
- `app.css` и `index.template.html` — оформление и структура страницы.

```bash
python3 scripts/build_standalone.py
```

Перед публикацией обязательны:

```bash
python3 scripts/build_standalone.py --check
node tests/test_core.js
node tests/test_economy.js
python3 scripts/validate_model.py
```

SharePoint получает только автономный `index.html`; файлы разработки и тесты в эксплуатационном контуре не выполняются.
