# Комментарии к модели

Комментарии формируются из данных выбранного договора при каждом расчёте. На «Своде» и в «Детальной модели» показывается один и тот же упорядоченный список; ручной текст и сведения из других договоров к нему не подмешиваются.

## Формат

Один пункт описывает одно условие: период и статья → значения с единицей → проверяемая причина или формула → действие. Причина, не доказанная источником, прямо обозначается предметом проверки. Нули и отклонения, которые после округления не видны, не порождают замечание. Один и тот же сигнал в пределах периода добавляется один раз. Суммы показываются в выбранной единице и валюте соответствующего года.

## Условия вывода

| Область | Условие | Что сообщает комментарий |
|---|---|---|
| Источники | Предварительный режим, блокировка, предупреждение или ошибка обновления | Период, конкретная проблема и требуемая сверка; успешная загрузка сама по себе не создаёт замечание. |
| BOQ / КСГ / KQ-2 | Строки без сопоставления либо оценки | Количество строк и действие по mapping или расценке. |
| Валюта | Нет положительного курса к RUB | Невозможность надёжного рублёвого сравнения. |
| Доходы | Доходы не равны выполнению по КСГ плюс прочие доходы | Явная корректировка и необходимость установить её источник. |
| Выполнение и КС-2 | Годовое выполнение не равно принятым актам | Обе суммы, разница и проверка срока актирования, факта и прогноза. Годовой разрыв сам по себе не означает потерянный доход. |
| Расходы | Общая сумма не равна прямым плюс косвенным либо группа не равна сумме её статей | Сумма неразнесённого расхождения; статью следует определить по первичным данным. |
| Факт затрат | Затраты перенесены из исторического источника | Источник переноса и запрос сверки с первичкой. |
| Ресурсы | График персонала или техники заканчивается раньше работ | Конкретный пробел; затраты и CF предварительны. |
| Аванс / ГУ | Остаток на конец года отличен от нуля | Остаток и проверка зачёта либо выплаты. При конфликте контрагента выводится отдельное условие. |
| Результат / CF | Финансовый результат отличается от CF за период | Обе суммы и отклонение, разложенное на поступления минус доходы, начисленные расходы минус выплаты и НДС. |
| Финансирование | Накопленный CF уходит ниже нуля | Минимум и проверка календаря выплат и поступлений. |
| Весь проект | Есть расчётная сверка выполнения и КС-2 | Выполнение, документные акты, исходный прогноз, распределённый остаток и итог актов после расчёта. |

Условия применяются отдельно к каждому году выбранного договора. Если документы не подтверждают экономическую причину расхождения, комментарий показывает формулу и предлагает сверку, не объявляя неподтверждённую причину установленным фактом.
