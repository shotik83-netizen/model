# Настройка источников финансово-экономической модели

Приложение не должно зависеть от фиксированных названий файлов, листов, строк заголовков или букв колонок. Все связи задаются через `config/source-mapping.json` и могут изменяться в режиме редактирования.

## Принцип из «Отчёта НЗС»

1. Пользователь явно запускает загрузку.
2. Приложение ищет строку заголовков по обязательным полям по всему листу.
3. Для каждого типа источника применяется сохранённый профиль.
4. Автоматически найденные соответствия показываются до загрузки.
5. Сомнительные соответствия требуют подтверждения.
6. Расчёт заблокирован до прохождения Check List.
7. Успешная настройка сохраняется как новая версия профиля и может быть отменена.

## Настраиваемые параметры

- путь или SharePoint URL;
- название листа и его псевдонимы;
- строка заголовков или автоматический поиск;
- первая и последняя строки данных;
- соответствие системных полей колонкам Excel;
- обязательность поля;
- тип и формат данных;
- правила очистки и преобразования;
- распознавание динамических колонок с датами;
- допустимые единицы измерения и валюты;
- правила дубликатов и приоритет источников.

## Размещение файлов

Эталонные источники находятся в `data/sources`. Пути в конфигурации относительные, поэтому каталог можно перенести, заменить SharePoint URL или переключить на другой набор файлов без изменения расчётного кода.

## Режим редактирования

Экран настройки должен показывать системное поле, найденную колонку, уверенность, образцы значений и результат проверки. Пользователь может выбрать другой лист или колонку, добавить псевдоним, изменить преобразование и сохранить версию профиля.

## Check List

До расчёта проверяются наличие обязательных источников и полей, даты, числовые значения, KQ, договор, подрядчик, валюта, единицы измерения, дубликаты и несопоставленные строки. Ошибки исходных документов не заменяются нулями.
