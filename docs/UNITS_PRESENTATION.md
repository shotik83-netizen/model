# Единицы денежных показателей

| Вариант | Где указана единица | Последствие |
|---|---|---|
| Только в верхнем переключателе | Один контроль для всей модели | При прокрутке длинной таблицы связь с числом теряется |
| В каждой числовой ячейке | Рядом с каждым значением | Таблицы становятся шире и хуже читаются на планшете |
| В переключателе и заголовке таблицы | Перед числами и при работе с таблицей | Повторяется один короткий ярлык, ширина месячных колонок не увеличивается |

Для текущего интерфейса принят третий вариант: масштаб и код валюты выбираются в верхнем контроле, денежные таблицы повторяют единицу в заголовке; натуральные значения подписаны у строк. KQ-2 и факторный анализ уже показывают денежную единицу у соответствующих колонок. Формулы и точность хранимых сумм этот выбор не меняет. Проверка читаемости на целевом планшете остаётся за пользователем.
