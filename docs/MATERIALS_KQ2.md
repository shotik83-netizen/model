# Материалы по видам работ KQ-2

## Реализованный этап

`BOQ!W` («Общая стоимость материалов и оборудования, USD») читается для каждой строки с кодом `BOQ!AF` и суммируется по KQ-2 независимо от стоимости СМР `BOQ!Y`. В таблице «Оценка KQ-2» обе суммы показаны в одной ячейке, чтобы сохранить компактную ширину экрана. Отсутствующее поле или пустая ячейка отображается прочерком; ноль, явно записанный в BOQ, отображается как ноль. Исходный BOQ не перезаписывается.

В режиме редактирования у каждой строки KQ-2 есть поле «Вид материала». Значение длиной до 80 символов хранится в `materialKinds` выбранной версии договора по нормализованному коду KQ-2. При смене версии назначения не смешиваются. После выгрузки файла подрядчика значения входят в его служебный лист `_DATA` и восстанавливаются при повторной загрузке. Повторная загрузка BOQ сохраняет назначения для существующих кодов; число назначений для исчезнувших кодов видно в предупреждении над таблицей. Чтобы удалить назначение, очистите поле. В обычном режиме сохранённое значение показано под названием работы.

В проверенном BOQ из 888 строк с кодом KQ-2 ненулевые значения `W` имеют только две строки, остальные 886 содержат числовой ноль. Поэтому показанная величина характеризует заполнение конкретного BOQ и не подтверждает полноту бюджета материалов.

## Следующий этап: назначение видов материалов и затрат

| Сущность | Источник и правило | Необходимое решение |
|---|---|---|
| Договорная стоимость МТР по работе | `BOQ!W`, сумма по KQ-2 | Уже показывается раздельно от СМР |
| Вид материала | Назначение пользователем по устойчивому коду KQ-2 и версии договора | Свободное наименование уже сохраняется; единый справочник и проверка синонимов требуют дальнейшей работы |
| План закупок и фактическая стоимость | Счета и первичные документы с датой, договором и ссылкой на KQ-2 | Поля источников, правила разнесения общих закупок и НДС |
| «Проектные материалы» в расходах модели | Подтверждённые затраты или согласованный план закупок по месяцам | Связать расход с месяцем и версией, не подставляя стоимость продажи из BOQ |

Поскольку SharePoint не даёт приложению автоматически переписать исходный документ, пользователь сохраняет скачанный файл подрядчика по установленному процессу. Назначение не изменяет исходные BOQ и КСГ. Данные пока доступны для приложения через `_DATA`, а не через отдельную редактируемую таблицу Excel.

## Проверки перед расчётом расходов

1. Сверить сумму `BOQ!W` по всем строкам с суммой по KQ-2 без округления.
2. Отдельно показать неназначенные и неоднозначные материалы.
3. Запретить двойной учёт, если закупка уже включена в другую расходную статью.
4. Не считать отсутствующее значение нулевым расходом и не выводить полный итог закупок при неполном покрытии первичкой.
