# Корректировки исходных рядов

В «Параметры → Корректировки исходных рядов» показаны 12 месяцев выбранной версии и колонка «В текущей модели». В ней отражено, куда попадает ряд при действующих правилах. Изменение вводов остаётся в памяти вкладки до выгрузки Excel подрядчика; замена источника может обновить эти ряды.

| Ряд | Применение |
|---|---|
| Физический объём, расценка BOQ, ручное выполнение | Если выбрана база КСГ и есть `ksgRevenue`, доход берётся из неё. Иначе, при наличии работ, берётся сумма объёмов работ × ставок. Без работ используется помесячно объём × расценка при ненулевой паре, иначе ручное выполнение. Физический ряд отдельно выводится в ТЭП. |
| Прочие доходы | Всегда добавляются к выполнению в доходах. |
| Материалы | При включённом прогнозе МТР из КСГ исходный ряд материалов не определяет статью; иначе он даёт базу проектных материалов при включённой статье и её расчётном методе. Ручное начисление статьи имеет приоритет. |
| Основной и косвенный персонал | Выводятся в ТЭП и используются в ФОТ и зависимых статьях, если их не перекрывают категории персонала, метод статьи или ручное начисление. |
| Вспомогательный персонал | Выводится в ТЭП; расчётное ядро расходов этот отдельный ряд не читает. |
| Трудоёмкость, пассивные работники, лесовики, дни исходной модели | Трудоёмкость влияет на питание/проживание при соответствующем признаке и на автобусы при режиме исходной Excel. Пассивные работники также влияют на медуслуги при режиме исходной Excel. Лесовики участвуют в лесомонтаже, базе проживания и автобусах в зависимости от выбранных признаков. Дни исходной модели применяются для питания/проживания при включённом режиме исходной Excel. |
| Маш.-ч, объём НРК | Дают базу соответствующей включённой статьи при расчётном методе; маш.-ч также выводятся в ТЭП. |
| Оплата работ, авансы, факторинг | Используются в денежном потоке. При расчёте прогноза по КСГ оплата работ может быть пересчитана через КС-2, удержания, зачёты и задолженность; закрытые месяцы остаются по документным рядам. |
| Зачёт аванса | В прогнозе по КСГ рассчитывается пропорционально, если выбран этот метод; при ручном методе берётся помесячный ряд. Он уменьшает задолженность и аванс, но не является повторным поступлением. |
| Выплата ГУ | Документный ряд погашает удержанный остаток; остаток может автоматически выплачиваться в месяце после последней КС-2 или в указанном месяце прогноза. |

Для статьи расходов ручной ряд начисления действует при включённой статье и методе `manual`. Ручной ряд выплаты, если существует, имеет приоритет над признаками выплаты и лагом статьи, включая факт, загруженный из исходной книги. Удаление такого ряда в настройках статьи возвращает расчётный график.

Статус строки описывает маршрут данных, но не доказывает, что ненулевая сумма прошла через все последующие условия. Подтверждённый факт актов и платежей следует обновлять из первичных документов: ручное редактирование денежных рядов меняет и закрытые месяцы.
